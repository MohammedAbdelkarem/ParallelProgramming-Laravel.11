About This File:

This file will be a small Docs to handle laravel new projects.
This will be as a small API starter kit.

=======================================================================================================================================
Init Steps:

- copy .env example
- php artisan install:api
- php artisan config:publish --all (Not Required)
- php artisan key:generate
- composer install (or update)
- php artisn storage:link

- Edit TODO:Template

=======================================================================================================================================
Ideas In This File:

1- Profile auth handling and profile creation and managements
2- Customer service cards
3- System info: Contact-us - About-us - Privacy Policies - Term Of Services - FAQ (الاسئلة الشائعة)
4- Stories
5- Banners
6- Notifications

=======================================================================================================================================
IMPORTANT:

1- Don't forget to copy .htaccess in public folder for security issues.
2- Copy config/_custom.php config file.

3- In storage/app/public copy the defaults and .gitignore file.
4- Copy Config Files and edit what is needed

5- Copy bootstrap folder and check it in (app.php and providers.php)
6- Check for jobs, rules and commands

7- Add helpers to composer.json: for autoload then run composer dump-autoload

Custom Middleware

**Required**

1- Tokens Middlewares	: CheckApiAccess - CheckOTPAccess - CheckRefreshAccess
2- User Middlewares	: UserActive     - UserBanned	  - UserCompleted      - UserVerified (According to project)

3- CheckBots		: Honeybot (Read more about it)
4- CheckLang		: Handle System Lang

5- CheckPerPage		: Handle $per_page params in request params for pagination
6- DatabaseTransaction	: Handle Database Queries in transactions

7- ForceJson		: ForceJson (Force request to be in json)
8- XSSProtection	: XSS attack handler (Read more about XSS)

=======================================================================================================================================
Custom Traits

**Required**

1- UniqueKey 		: Generate OTP and unique string
2- StringHelper 	: Handle strings in many ways
3- StorageHelper 	: Hanlde storing and deleting files and directories (This is more required to handle media if You don't use medialibrary)

**Not Required**

1- TimeFormatter	: Used in formation time string the in many customized ways
2- NotificationHelper	: Used to handle notifications cases
